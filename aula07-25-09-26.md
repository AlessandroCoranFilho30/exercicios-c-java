# Exercício 1 ✅
Cálculo do dígito verificador do CPF.
Primeiro dígito
Pegue os 9 primeiros dígitos do CPF. 
Multiplique cada dígito por uma sequência decrescente de 10 até 2. 
Some todos os resultados das multiplicações. 
Divida a soma total por 11.
Analise o resto da divisão:
Se o resto for menor que 2, o dígito é 0
Se o resto for 2 ou mais, o dígito é 11 menos o resto.
Segundo dígito
Pegue os 9 primeiros dígitos mais o 1º dígito verificador recém-calculado.
Multiplique os 10 dígitos por uma sequência decrescente de 11 até 2. 
Some todos os novos produtos. 
Divida a nova soma por 11.
Aplique a mesma regra do resto:
Se o resto for menor que 2, o dígito é 0.
Se o resto for 2 ou mais, o dígito é 11 menos o resto.


## Java

```java
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int[] cpf = new int[9];

    System.out.print("Digite os 9 primeiros dígitos do CPF em uma linha: ");
    String entrada = sc.nextLine().replaceAll("\\D", ""); // "\\D" remove tudo que não é número

    for (int i = 0; i < cpf.length; i++) {
      cpf[i] = entrada.charAt(i) - '0';
    }

    int soma = 0;
    for (int i = 0; i < cpf.length; i++) {
      soma += cpf[i] * (10 - i);
    }

    int resto = soma % 11;
    int primeiroDigito = resto < 2 ? 0 : 11 - resto;

    soma = primeiroDigito * 2;
    for (int i = 0; i < cpf.length; i++) {
      soma += cpf[i] * (11 - i);
    }

    resto = soma % 11;
    int segundoDigito = resto < 2 ? 0 : 11 - resto;

    System.out.println("Dígitos: " + primeiroDigito + segundoDigito);
    sc.close();
  }
}
```

```c
    int segundoDigito = resto < 2 ? 0 : 11 - resto;

    printf("Digitos: %i%i", primeiroDigito, segundoDigito);
  }
```


# Exercício 2 ✅
Dado um vetor de n elementos inteiros, desenvolva um programa que identifique valores repetidos no mesmo bem como sua frequência. Exemplo:
{7,9,4,3,7,2,4,9,1,7}
9 repete 2 vezes
7 repete 3 vezes
4 repete 2 vezes

## Java
```java
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner sc = new Scanner (System.in);
    int numero;

    System.out.print("Quantos números serão digitados: ");
    int n = sc.nextInt();

    int contador[] = new int[10];

    for (int i = 0; i < n; i++) {
        System.out.printf("Número %d: ", i + 1);
        numero = sc.nextInt();
        contador[numero]++;
    }

    System.out.println("Números repetidos:");

    for (numero = 0; numero <= 9; numero++) {
        if (contador[numero] > 1) {
            System.out.printf("%d aparece %d vezes\n", numero, contador[numero]);
        }
    }

    sc.close();
  }
}
```
