# Aula 6 - Vetores
## Definição
Um vetor é uma variável composta homogênea unidimensional formada por uma sequência de variáveis todas de mesmo tipo, com o mesmo identificador, como nome, idade.
Uma vez que as variáveis têm o mesmo nome, o que distingue é um índice, que referência sua localização dentro da estrutura

### Exemplo:
int idade[10];
float salario [10];

A alocação destes dados é estática, ou seja, o compilador bate o olho na linha acima e aloca um endereço de memória variável. Exemplo:

## Atividade 1 ✅
Dado um conjunto N de elementos do tipo inteiro, identifique os números ímpares e a soma dos pares.

## Java
```java
import java.util.Scanner;

public class Main {
public static void main(String[] args) {
  Scanner sc = new Scanner(System.in);

	int contadorImpar = 0;
	int numeros = 0;
  int par = 0;

	System.out.print("Quantos números serão digitados? ");
  int digitos = sc.nextInt();

	for (int i = 0; i < digitos; i++) {
		System.out.print("Número: ");
    numeros = sc.nextInt();

		if (numeros % 2 == 0) {
            par += numeros;
		} else {
            contadorImpar++;
		}
	}

    System.out.printf("Soma dos pares: %d \n", par);
    System.out.printf("Números ímpares: %d", contadorImpar);

    sc.close();
}
}
```

## Atividade 2 ✅
Dado um conjunto de N elementos do tipo inteiro, identifique e armazene em dois vetores de processamento, ou resultante os números pares e ímpares.

## Java
```java
import java.util.Scanner;

public class Main {
  public static void main (String[] args) {
    Scanner sc = new Scanner (System.in);

    int contadorPar = 0;
    int contadorImpar = 0;

    System.out.print("Informe a quantidade de elementos no vetor: ");
    int quantidade = sc.nextInt();

    int vetor[] = new int [quantidade];
    int par[] = new int [quantidade];
    int impar[] = new int [quantidade];

    for (int i = 0; i < quantidade; i++) {
      System.out.print("Número: ");
      vetor[i] = sc.nextInt();
    }

    for (int i = 0; i < quantidade; i++) {
        if (vetor[i] % 2 == 0) {
            contadorPar++;
            par[contadorPar] = vetor[i];
        } else {
            contadorImpar++;
            impar[contadorImpar] = vetor[i];
        }
    }

    System.out.printf("Valores armazenados no par: %d \n", contadorPar);
    System.out.printf("Valores armazenados no ímpar: %d \n", contadorImpar);
    
    sc.close();
  }
  }
```

## Atividade 3 ✅
Desenvolva um programa que carregue um vetor contendo nome do produto, um vetor a quantidade e outro o valor. Estabeleça um vetor resultante que armazene os nomes do produto que estejam abaixo da quantidade de 10 peças em estoque. No final, exibir os produtos.
Embora a declaração da String seja uma matriz, a sua operação seja um vetor conforme exemplo abaixo:

```code
for (int i = 0; i < 10; i++) {
    fgets(Produto[i], 20, stdin);
    Produto[i][strcspn(Produto[i], "\n")] = '\0';
}
```

## Java

```java
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner sc = new Scanner (System.in);
    int quantidade[] = new int[10];
    int i = 0;
    int j = 0;
    int k = 0;

    System.out.print("Digite a quantidade de valores a ser digitado: ");
    int n = sc.nextInt();
    
    char produto[] = new char[n];
    char saida[] = new char[n];

    for (i = 0; i < n; i++) {
      System.out.print("Nome do produto: ");
      produto[i] = sc.next().charAt(0);
      
      System.out.print("Quantidade: ");
      quantidade[i] = sc.nextInt();
    }

    for (i = 0; i < n; i++) {
      if (quantidade[i] < 5) {
        saida[k] = produto[i];
        k++;
      }
    }

    for (i = 0; i < k; i++) {
      System.out.printf("Produto identificado: %c", saida[i]);
    }
    sc.close();
}
}
```
