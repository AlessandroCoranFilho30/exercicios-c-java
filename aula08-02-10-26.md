# Exercício 1 ✅
Crie um programa em que se possa adicionar o nome de vários produtos, que serão armazenados em um vetor, e depois analisar o produto e permitir buscar do programa se tem o produto no estoque ou não.

## Java
```java
package app;

import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String[] busca = new String[1];
        String[] produto = new String[10];
        int i, achou;

        System.out.print("Informe o nome dos produtos (10): ");

        for (i = 0; i < 10; i++) {
            produto[i] = sc.nextLine();
        }

        System.out.print("Informe o nome do produto a ser consultado: ");
        busca[0] = sc.nextLine();

        achou = 0;
        i = 0;

        while (i < 10) {
            if (busca[0].equals(produto[i])) {
                System.out.printf("Elemento consta no estoque na posição: %d", i+1);
                achou = 1;
                break;
            } else {
                i++;
            }
        }

        if (achou == 0) {
            System.out.print("Produto não consta no estoque");
        }
        sc.close();
    }
}
```

## C

```c
    fgets(busca, 20, stdin);


    achou = 0;
    i = 0;


    while (i < 10) {
        if (strcmp(busca, produto[i]) == 0) {
            printf("Elemento consta no estoque na posição: %d", i+1);
            system("pause");
            achou = 1;
            break;
        } else {
            i++;
        }
    }

    if (achou == 0) {
        printf("Produto não consta no estoque");
        system("pause");
    }
}
```

# Exercício 2 ✅
Dado um vetor de nome de aluno e um vetor das médias dos alunos, desenvolvam um programa que gere um vetor resultante que armazene o nome dos alunos que vier apresentar média abaixo de 6.0. No final exibir o vetor resultante.

## Java
```java
package app;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int k = 0;

        System.out.print("Informe a quantidade de alunos: ");
        int n = sc.nextInt();

        String[] aluno = new String[n];
        double[] media = new double[n];
        String[] reprovados = new String[n];

        for (int i = 0; i < n; i++) {
            System.out.print("Informe o nome do aluno: ");
            sc.nextLine();
            aluno[i] = sc.nextLine();

            System.out.print("Informe a media do aluno: ");
            media[i] = sc.nextDouble();
        }

        for (int i = 0; i < n; i++) {
            if (media[i] < 6) {
                k++;
                reprovados[k] = aluno[i];
            }
        }

        System.out.println("Alunos reprovados: ");
        for (int i = 1; i <= k; i++) {
            System.out.printf("%s", reprovados[i]);
        }
        sc.close();
    }
}
```
