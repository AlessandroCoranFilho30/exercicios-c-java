# Exercício 1 ✅
Foi feita uma pesquisa entre os habitantes de uma região. Foram coletados os dados de idade, sexo (M/F) e salário. Faça um programa que calcule e mostre:
a média dos salários do grupo
a maior e a menor idade do grupo
a quantidade de mulheres com salário até R$200,00
a idade e o sexo da pessoa que possui o menor salário

## Java

```java
package app;

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        char sexo, op;
        char idxSexo = '0';
        int idade;
        int idadeM = 0;
        int k = 0;
        int j = 0;
        int maior = 0;
        int menor = 0;
        float salario, media;
        float totalSalario = 0;
        float menorSalario = 6000;

        do {
            k++;
            System.out.println("Funcionário de numero: " + k);

            System.out.print("Informe o salario da pessoa: ");
            salario = sc.nextFloat();

            System.out.print("Informe o sexo da pessoa: ");
            sexo = sc.next().charAt(0);

            System.out.print("Informe a idade da pessoa: ");
            idade = sc.nextInt();

            totalSalario += salario;

            if (idade > maior) {
                maior = idade;
            }

            if (idade < menor) {
                menor = idade;
            }

            if (sexo == 'F' || sexo == 'f' && (salario < 1600)) {
                j++;
            }

            if (salario < menorSalario) {
                menorSalario = salario;
                idadeM = idade;
                idxSexo = sexo;
            }

            System.out.print("Deseja continuar ou digitar outro funcionario? [S]im | [N]ao: ");
            op = sc.next().charAt(0);
        } while (op != 'N');

        media = totalSalario / k;

        System.out.println("----------------------------");
        System.out.printf("Media do salario da empresa %.2f", media);
        System.out.printf("Maior idade %d e a menor idade %d", maior, menor);
        System.out.printf("Quantidade de mulheres com salario abaixo de R$1600 %d", j);
        System.out.printf("Idade da pessoa de menor salario: %d, pertence ao sexo: %c e possui o menor salario: %.2f", idadeM, idxSexo, menorSalario);

        sc.close();
    }
}
```

# Exercício 2 ✅
Escreva um programa que leia um número e exiba a sua tabuada de multiplicação.
Desenvolva um programa que mostre as tabuadas de multiplicação de todos os números inteiros de 1 a 10.

## Java

```java
package app;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
      Scanner sc = new Scanner (System.in);

      int resultado = 0;

      System.out.print("Digite um número: ");
      int n = sc.nextInt();

      for (int i = 0; i <= 10; i++) {
        resultado = n * i;
        System.out.printf("%d x %d = %d \n", n, i, resultado);
      }
      sc.close();
    }

}
```
