# Matriz

Uma matriz é uma variável composta homogênea bidimensional formada por uma sequência de variáveis, todas de mesmo tipo com o mesmo identificador (mesmo nome) e alocadas sequencialmente na memória.
Uma vez que as variáveis têm o mesmo nome, o que as distingue são os índices que referenciam sua localização dentro da estrutura. Uma matriz é composta por linha e coluna.

## Declaração de matriz
```c
int matriz[3][3];
```

```c
#include <stdio.h>
int main() {
    int i, j;
    int matriz[3][3];

    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            scanf("%d", &matriz[i][j]);
        }
    }

    for (i = 0; i < 3; i++) {
        printf("\n\n");
        for (j = 0; j < 3; j++) {
            printf("\t%d", matriz[i][j]);
        }
    }
}
```

## Calcular linha
```c
#include <stdio.h>
int main() {
    int i, j;
    int matriz[3][3];
    int soma;

    for (int i = 0; i < 3; i++) {
        soma = 0;
        for (int j = 0; j < 3; j++) {
            scanf("%d", &matriz[i][j]);
            soma += matriz[i][j];
        }
        printf("\t%i\n", soma);
    }

    for (i = 0; i < 3; i++) {
        printf("\n\n");
        for (j = 0; j < 3; j++) {
            printf("\t%d", matriz[i][j]);
        }
    }
}
```

## Calcular coluna
```c
#include <stdio.h>
int main() {
    int i, j;
    int matriz[3][3];
    int coluna;

    for (int j = 0; j < 3; j++) {
        coluna = 0;
        for (int i = 0; i < 3; i++) {
            scanf("%d", &matriz[i][j]);
            coluna += matriz[i][j];
        }
        printf("\t%i\n", coluna);
    }

    for (i = 0; i < 3; i++) {
        printf("\n\n");
        for (j = 0; j < 3; j++) {
            printf("\t%d", matriz[i][j]);
        }
    }
}
```
