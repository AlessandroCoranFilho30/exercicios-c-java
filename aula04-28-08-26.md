# Exercício 1 ✅
Desenvolva um programa que receba os dados a seguir de vários produtos:
- Preços unitários
- País de origem (1- EUA, 2- MÉXICO e 3- OUTROS)
- Meio de transporte (T-terrestre, F-fluvial e A-aéreo)
- Carga perigosa (S - sim e N- não)

Calcule e mostre:

Imposto do produto:

| Preço unitário | Imposto em % |
|--------------|----------------|
| Até R$100,00 | 5% |
| Acima de R$100,00 | 10%|


Valor do frete:

| Carga perigosa | País de origem | Valor do transporte |
|----------------|----------------|---------------------|
| Sim | 1 - EUA, 2 - MÉXICO, 3 - OUTROS | R$50,00 - R$35,00 - R$24,00 |
| Não | 1 - EUA, 2 - MÉXICO, 3 - OUTROS | R$12,00 - R$35,00 - R$60,00 |


Valor do seguro - conforme requisitos abaixo:
Os produtos que vêm do México e que utilizam transporte aéreo pagam metade do valor de imposto sobre o total do produto. Exemplo:
Total = (Preço + Frete + Imposto). Os demais produtos estão isentos.

## Java

```java
package app;

import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int paisOrigem = 0;
        double imposto = 0;
        double precoUnitario = 0;
        double valorTransporte = 0;
        double impostor = 0;
        double valorSeguro = 0;
        char cargaPerigosa = '0';
        char meioTransporte = '0';

        System.out.print("Numero total de produtos: ");
        int produtos = sc.nextInt();

        do {
            System.out.print("Preco unitario: ");
            precoUnitario = sc.nextDouble();

            System.out.print("Pais de origem (1. EUA, 2.MEXICO, 3.OUTROS): ");
            paisOrigem = sc.nextInt();

            System.out.print("Meio de transporte (T. Terrestre, F.Fluvial, A.Aereo): ");
            meioTransporte = sc.next().charAt(0);

            System.out.print("Carga perigosa? (S/N)?: ");
            cargaPerigosa = sc.next().charAt(0);

            // Imposto do produto
            if (precoUnitario <= 100.00) {
                imposto = 0.05;
                impostor = precoUnitario * imposto;
            } else if (precoUnitario > 100.00) {
                imposto = 0.10;
                impostor = precoUnitario * imposto;
            }

            // Valor do frete
            if (cargaPerigosa == 'S' || cargaPerigosa == 's') {
                if (paisOrigem == 1) {
                    valorTransporte = 50.00;
                } else if (paisOrigem == 2) {
                    valorTransporte = 35.00;
                } else if (paisOrigem == 3) {
                    valorTransporte = 24.00;
                }
            } else if (cargaPerigosa == 'N' || cargaPerigosa == 'n') {
                if (paisOrigem == 1) {
                    valorTransporte = 12.00;
                } else if (paisOrigem == 2) {
                    valorTransporte = 35.00;
                } else if (paisOrigem == 3) {
                    valorTransporte = 60.00;
                }
            }

            // Valor do seguro
            if (paisOrigem == 2 && (meioTransporte == 'A' || meioTransporte == 'a')) {
                valorSeguro = (precoUnitario + valorTransporte + impostor) / 2;
            } else {
                valorSeguro = 0; // Isento
            }

            System.out.println("-----------------------");
            System.out.printf("Imposto do produto: %.2f%% | R$%.2f \n", imposto * 100, impostor);
            System.out.printf("Valor do frete: R$%.2f \n", valorTransporte);
            System.out.printf("Valor do seguro: R$%.2f \n", valorSeguro);
            System.out.println("-----------------------");
            produtos--;
        } while (produtos > 0);
        sc.close();
    }
}
```
