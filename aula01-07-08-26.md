# Exercício 1 ✅
O Supermercado estava fazendo uma promoção, onde compras acima de R$300,00 recebem desconto de 10% do valor acima de R$300,00.

## Java

```java
package app;
import java.util.Scanner;

public class Main {
    public static void main (String[] args) {
        Scanner sc = new Scanner (System.in);
        
        double total = 0;
        
        System.out.print("Digite o valor total da compra: R$");
        double compra = sc.nextDouble();
        
        if (compra <= 300) {
            System.out.println("Promoção não se enquadra!");
            total = compra;
        } else {
            double valorExecedido = (compra - 300) * 0.10;
            total = total + compra - valorExecedido;
        }
        
        System.out.printf("R$ %.2f", total);
        sc.close();
    }
}
```

# Exercício 2 ✅
Existem 3 departamentos com N funcionários cada, pergunte o número de funcionários em cada departamento, o salário padrão para todos e retorne:
Total geral de salário em cada departamento
Total de todos os departamentos (A + B + C)
Maior salário digitado e qual departamento (ex: Salário R$ 5000, departamento C)

## Java

```java
package app;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double totalSalarioA = 0;
        double totalSalarioB = 0;
        double totalSalarioC = 0;
        double salarioGeral = 0;
        double maiorSalario = 0;
        char qualDepartamento = '0';

        System.out.print("Quantos funcionários departamento A? ");
        int funcionariosA = sc.nextInt();

        double[] departamentoA = new double[funcionariosA];

        for (int i = 0; i < funcionariosA; i++) {
            System.out.print("Digite o salário do funcionário: ");
            departamentoA[i] = sc.nextInt();
            totalSalarioA += departamentoA[i];
            salarioGeral += departamentoA[i];
        }

        System.out.print("Quantos funcionários departamento B? ");
        int funcionariosB = sc.nextInt();

        double[] departamentoB = new double[funcionariosB];

        for (int i = 0; i < funcionariosB; i++) {
            System.out.print("Digite o salário do funcionário: ");
            departamentoB[i] = sc.nextInt();
            totalSalarioB += departamentoB[i];
            salarioGeral += departamentoB[i];
        }

        System.out.print("Quantos funcionários departamento C? ");
        int funcionariosC = sc.nextInt();

        double[] departamentoC = new double[funcionariosC];

        for (int i = 0; i < funcionariosC; i++) {
            System.out.print("Digite o salário do funcionário: ");
            departamentoC[i] = sc.nextInt();
            totalSalarioC += departamentoC[i];
            salarioGeral += departamentoC[i];
        }

        if (totalSalarioA > totalSalarioB) {
            if (totalSalarioA > totalSalarioC) {
                maiorSalario = totalSalarioA;
                qualDepartamento = 'A';
            } else {
                if (totalSalarioB > totalSalarioC) {
                    maiorSalario = totalSalarioB;
                    qualDepartamento = 'B';
                } else {
                    maiorSalario = totalSalarioC;
                    qualDepartamento = 'C';
                }
            }

        } else {
            if (totalSalarioB > totalSalarioC) {
                maiorSalario = totalSalarioB;
                qualDepartamento = 'B';
            } else {
                maiorSalario =  totalSalarioC;
                qualDepartamento = 'C';
            }
        }

        // Total geral salário por departamento (ex: A 100, B 20, C 500)
        System.out.println("Total salários todos os departamentos:");
        System.out.printf("Departamento A: R$%.2f \n", totalSalarioA);
        System.out.printf("Departamento B: R$%.2f \n", totalSalarioB);
        System.out.printf("Departamento C: R$%.2f \n", totalSalarioC);

        // Maior salário digitado e qual departamento (ex: salário = 5, dep A)
        System.out.println("-----------------------------");
        System.out.println("Maior salário digitado e de qual departamento:");
        System.out.printf("Salário: R$%.2f, Departamento: %c \n", maiorSalario, qualDepartamento);

        // Somar todos os salários todos departamentos (A + B + C)
        System.out.println("-----------------------------");
        System.out.printf("Salário geral todos os departamento: %.2f", salarioGeral);

        sc.close();
    }
}
```

# Exercício 3 ✅
Programa que pergunta a quantidade de pessoas que serão digitadas, depois pede altura, idade e peso de cada uma e retorna:
Quantas tem idade +18
Quantas tem mais de 160 cm
Média de peso

## Java

```java
package app;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int contadorIdade = 0;
        int contadorAltura = 0;

        System.out.print("Quantas pessoas? ");
        int quantasPessoas = sc.nextInt();

        int[] idade = new int[quantasPessoas];
        int[] altura = new int[quantasPessoas];
        int peso = 0;

        for (int i = 0; i < quantasPessoas; i++) {
            System.out.print("Idade: ");
            idade[i] = sc.nextInt();

            System.out.print("Peso (Kg): ");
            peso += sc.nextInt();

            System.out.print("Altura (cm): ");
            altura[i] = sc.nextInt();
            System.out.println("------------------");
        }

        // idade igual ou maior  de 18
        for (int i = 0; i < quantasPessoas; i++) {
            if (idade[i] >= 18) {
                contadorIdade++;
            }

            if (altura[i] > 170) {
                contadorAltura++;
            }
        }

        int mediaPeso = peso / quantasPessoas;

        System.out.println("Quantidade pessoas idade igual ou maior que 18 anos: " + contadorIdade);
        System.out.println("Quantidade pessoas altura maior que 170cm: " + contadorAltura);
        System.out.println("Media de peso das pessoas digitadas: " + mediaPeso);
        sc.close();
    }
}
```
