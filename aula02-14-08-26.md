# Exercício 1 ✅
Simular uma folha de pagamento, perguntando as horas trabalhadas, o salário por hora trabalhada. Retorne o salário bruto, o salário líquido, o total descontado e o desconto do INSS e IRRF.

## Java

```java
package app;
import java.util.Scanner;

public class Main {
    public static void main(String[] Args) {
        Scanner sc = new Scanner(System.in);

        double aliquotaInss = 0;
        double aliquotaIrrf = 0;
        double parcelaDeduzirInss = 0;
        double parcelaDeduzirIrrf = 0;

        System.out.println("Quantas horas trabalhadas? ");
        int horasTrabalhadas = sc.nextInt();

        System.out.println("Qual salário por hora? ");
        double salarioHora = sc.nextDouble();

        double salarioBruto = horasTrabalhadas * salarioHora;

    if (salarioBruto <= 1621) {
        aliquotaInss = 0.07;
        aliquotaIrrf = 0.00;
        parcelaDeduzirInss = 0;
        parcelaDeduzirIrrf = 0;
    } else if (salarioBruto <= 2902) {
        aliquotaInss = 0.09;
        aliquotaIrrf = 0.075;
        parcelaDeduzirInss = 24.32;
        parcelaDeduzirIrrf = 18.20;
    } else if (salarioBruto <=4354) {
        aliquotaInss = 0.12;
        aliquotaIrrf = 0.15;
        parcelaDeduzirInss = 111.40;
        parcelaDeduzirIrrf = 394.16;
    } else {
        aliquotaInss = 0.14;
        aliquotaIrrf = 0.275;
        parcelaDeduzirInss = 198.49;
        parcelaDeduzirIrrf = 908.73;
    }

    double calculoInss = (salarioBruto * aliquotaInss) - parcelaDeduzirInss;
    double calculoIrrf = (salarioBruto * aliquotaIrrf) - parcelaDeduzirIrrf;
    double descontoTotal = calculoInss + calculoIrrf;
    double salarioLiquido = salarioBruto - descontoTotal;

        System.out.println("-----------------------");
        System.out.printf("Salário Bruto: %.2f \n", salarioBruto);
        System.out.printf("Salário Líquido %.2f \n", salarioLiquido);
        System.out.println("-----------------------");
        System.out.printf("Desconto Total: %.2f \n", descontoTotal);
        System.out.printf("Desconto INSS: %.2f \n", calculoInss);
        System.out.printf("Desconto IRRF: %.2f \n", calculoIrrf);

        sc.close();
    }
}
```

# Exercício 2 ✅
Em um fábrica trabalham homens e mulheres divididos em três classes:
Classe 1: trabalhadores que produzem até 30 peças por mês
Classe 2: trabalhadores que produzem entre 31 até 35 peças por mês
Classe 3: trabalhadores que produzem acima de 35 peças por mês

Classe 1 recebe um salário mínimo, a classe 2 recebe salário mínimo mais 3% do salário mínimo por peça, acima de 30 peças iniciais, a classe 3 recebe salário mais 5% do salário mínimo por peça acima de 35 peças.
Desenvolva um programa que receba o prontuário, o número de peças produzidas e o sexo do funcionário. Calcule e mostre:
O prontuário do operador e seu salário
O total da folha de pagamento da fábrica
A média de peças fabricadas pelas mulheres
A média de peças fabricadas pelos homens
O prontuário do funcionário ou funcionária de maior salário
Ler N recibos

## Java

```java
package app;
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        double salarioBasico = 1000;
        double salarioMinimo;
        double mediaHomens = 0;
        double mediaMulheres = 0;
        int contadorM = 0;
        int contadorF = 0;
        double folhaDePagamento = 0;

        System.out.print("Quantos funcionários(as): ");
        int funcionarios = sc.nextInt();
        sc.nextLine();

        double[] maiorSalario = new double[funcionarios];
        char[] sexo = new char[funcionarios];
        int[] pecaMensal = new int [funcionarios];

        for (int i = 0; i < funcionarios; i++) {
            System.out.print("Sexo do funcionário(a): ");
            sexo[i] = sc.next().charAt(0);

            System.out.print("Peças por mês: ");
            pecaMensal[i] = sc.nextInt();

            if (pecaMensal[i] <= 30) { // Classe 1
                salarioMinimo = salarioBasico;
                folhaDePagamento += salarioBasico;
                maiorSalario[i] = salarioBasico;
            } else if (pecaMensal[i] > 30 && pecaMensal[i] <= 35) { // Classe 2
                salarioMinimo = salarioBasico + (0.03 * (pecaMensal[i] - 30));
                maiorSalario[i] = salarioMinimo;
                folhaDePagamento += salarioMinimo;
            } else { // Classe 3
                salarioMinimo = salarioBasico + (0.05 * (pecaMensal[i] - 35));
                maiorSalario[i] = salarioMinimo;
                folhaDePagamento += salarioMinimo;
            }

            if (sexo[i] == 'm' || sexo[i] == 'M') { // Masculino
                mediaHomens += pecaMensal[i];
                contadorM++;
            }

            if (sexo[i] == 'f' || sexo[i] == 'F') { // Feminino
                mediaMulheres += pecaMensal[i];
                contadorF++;
            }
            System.out.printf("Sexo: %s \nsalário %.2f \n", sexo[i], salarioMinimo);
        }

        if (contadorM > 0) {
            mediaHomens /= contadorM;
        } else {
            mediaHomens = 0;
            System.out.println("Nenhum funcionário masculino!");
        }

        if (contadorF > 0) {
            mediaMulheres /= contadorF;
        } else {
            mediaMulheres = 0;
            System.out.println("Nenhuma funcionária feminina!");
        }

        Arrays.sort(maiorSalario);
        double maior = maiorSalario[maiorSalario.length - 1];

        System.out.println("----------------------------");
        System.out.printf("Total Folha de Pagamento: R$%.2f \n", folhaDePagamento);
        System.out.printf("Média de Peças Fabricadas Homens: %.2f \n",  mediaHomens);
        System.out.printf("Média de Peças Fabricadas Mulheres: %.2f \n",  mediaMulheres);
        System.out.printf("Maior Salário: R$%.2f\n", maior);
        sc.close();
    }
}
```
