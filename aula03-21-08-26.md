# Exercício 1 ✅
Uma empresa decidiu fazer um levantamento em relação aos candidatos que se apresentaram para preenchimento das vagas no seu quadro de funcionários. Supondo que você seja desenvolvedor dessa empresa, desenvolva um programa que lê para cada candidato:
Idade
Sexo (M ou F)
Experiência no serviço (S/N)
Calcule e mostre:
Número de candidatos do sexo feminino
Número de candidatos do sexo masculino
A idade média dos homens que já tem experiência
A porcentagem dos homens com mais de 45 anos em relação ao total de homens
O número de mulheres com menos de 35 anos e com experiência no serviço
## Java

```java
package app;

import java.util.Scanner;

public class Main {
	public static void main (String[] args) {
		Scanner sc = new Scanner(System.in);
		int idade = 0;
		int velho = 0;
		int xp = 0;
		int contadorM = 0;
		int contadorF = 0;
		int mulher = 0;
		char sexo, temExperiencia;
		float mediaIdadeHomensExperiencia = 0;
		float idadeMedia = 0;
		float homensVelhos = 0;

		System.out.print("Numero total de candidatos: ");
		int candidatos = sc.nextInt();

		for (int i = 0; i < candidatos; i++) {
			System.out.print("Idade: ");
			idade = sc.nextInt();

			System.out.print("Sexo (M / F): ");
			sexo = sc.next().charAt(0);

			System.out.print("Tem experiencia?: ");
			temExperiencia = sc.next().charAt(0);

			if (sexo == 'm' || sexo == 'M') {
				contadorM++;

				if (temExperiencia == 's' || temExperiencia == 'S') {
					mediaIdadeHomensExperiencia += idade;
					xp++;
				}

				if (idade > 45) {
					velho++;
				}
			} else {
				contadorF++;

				if (idade < 35 && (temExperiencia == 's' || temExperiencia == 'S')) {
					mulher++;
				}
			}
		}

		if (xp > 0) {
			idadeMedia = mediaIdadeHomensExperiencia / xp;
		} else {
			idadeMedia = 0;
		}

		if (contadorM > 0) {
			homensVelhos = ((float) velho / contadorM) * 100;
		} else {
			homensVelhos = 0;
		}

		System.out.println("----------------------------");
		System.out.printf("Total candidatos masculinos: %d \n", contadorM);
		System.out.printf("Total candidatas femininas: %d \n", contadorF);
		System.out.printf("Idade media homens com experiencia: %.2f \n", idadeMedia);
		System.out.printf("Porcentagem homens idade > 45 anos: %.2f \n", homensVelhos);
		System.out.printf("Mulheres com menos de 35 anos e com experiência: %d", mulher);
		sc.close();
	}
}
```
